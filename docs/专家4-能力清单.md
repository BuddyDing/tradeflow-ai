## 1. Persona / 人设

来源：`tradeflow/prompts/ads.md`（两形态共用）。已从「广告优化师」扩展为「店铺运营」：

- **角色**：资深亚马逊店铺运营，看商品交易、广告、成本报表，做**商品问题定位、广告词优化、盈亏诊断**。
- **职责**：交易诊断（调 `analyze_transactions` 按 SKU 看销量/销售额/平台费后到手/退款率/平台费，定位高退款/低毛利/异常扣费）；广告优化（以 SKU 盈亏平衡 ACOS 判词、给加价/降价/否定动作）。
- **核心原则**：**按当前可用数据给出能给的最强结论**，同时主动引导补哪些数据能得更强结论——不停在「数据不足」。
- **边界**：只给建议不改后台；缺成本时只到「平台费后到手」，不声称利润/亏损金额；工具返回「数据来源=示例数据」时必须在回复开头醒目标注。

## 2. Skills / 判断规则（`skills/ads/` 下两个文件，按文件名拼接）

### 2a. `调词控ACOS规则.md` —— 广告 SOP
盈亏线三级优先级（真实/估算/默认）、搜索词三分类（垃圾词/好词/潜力长尾词/观察）及对应动作、灰区处理、报告习惯。阈值外置在 `data/ads/调词规则.csv`（改表不改代码）。

### 2b. `商品交易诊断规则.md` —— 交易 SOP（本次新增）
- **口径**：销售额（未扣费）、平台费后到手（total，扣佣金/FBA/退款/税后，**非净利**）、平台费（佣金+FBA）。缺采购成本时禁止声称利润/亏损。
- **问题商品判定**：高退款率（≥15%可调）、低毛利（平台费后毛利率<30%可调）、负向调整/扣费；高销量优先处理。
- **部分信息也出结论 + 引导补数据**：只有交易报告 → 给销售额/到手/退款率/问题商品并标注口径；+成本表 → 真实净利/毛利/盈亏ACOS；+广告报告 → 每个 SKU 广告是否盈利。用工具返回的 `next_steps` 主动引导。

## 4. 字段映射体系（本次新增，根治「任意表头」）

识别不再只靠固定列名，而是「自动识别 + 人工指认兜底 + 存映射复用」三层：

1. **标准字段**：`web/import_service.py::ALIASES` 定义业务字段（sku、txn_type、sales、net_amount、selling_fees、fba_fees、purchase_cost、freight、unit_cost…）及其中英文别名。导入时 `save_import` 把命中的列**重命名为标准字段名**存库。
2. **自动识别**：`suggest_mapping` 按别名字典精确匹配（归一化大小写/空格）。命中的自动映射。
3. **人工指认兜底**：前端映射 UI（`prototype.html`）每列一个下拉（含交易/成本全部字段选项）；**未识别的列高亮标黄 +「⚠ 未识别，请指认」**，用户手动指认或设为忽略。
4. **存映射复用**：`saved_mappings` 表按「列名指纹」记住用户确认过的映射；下次同表头 preview **自动复用**（`reused_mapping`），免去重复指认。
5. **工具依赖标准字段**：`analyze_transactions` 认标准字段名（用户映射后的键）+ 兼容原始英文名；交易类型值经 `_txn_kind` 归一（Order/订单、Refund/退款）。→ **换任意表头命名，映射确认后工具都能算准。**

## 5. 系统提示拼装 + SOP 注入范围

- **BASE**（`tradeflow/prompts/__init__.py::BASE_SYSTEM_PROMPT`）：全局铁律（数字只能来自工具、不编造、区分事实/估算、失败如实说…）。
- **磁盘形态**：`compose_system_prompt("ads")` = BASE + 人设(ads.md) + 两份 skills。
- **数据库形态**：通用导入提示 + `_ads_expert_sop()`（= 人设 + 两份 skills + 护栏）。
- **注入范围**：`_ads_expert_sop` 在 scope ∈ {`ads_search_terms`, `orders`, `multi`} 时注入；`orders` 指令点名优先调 `analyze_transactions`。

## 6. 数据流（一图看懂）

```
上传报表 → preview（自动识别 + 未识别高亮，复用历史映射）
        → 用户确认映射 → save_import（重命名为标准字段入库，记住映射）
        → 专家4 数据库形态 → analyze_transactions / 广告工具（认标准字段）
        → 按 SKU 问题定位 + 广告动作 + 口径说明 + 引导补数据
```
